
## Empirical runtime challenge receipts

Cognitive challenge inputs are bounded, encrypted in the content vault at rest, exposed only to the execution envelope, and exercised through the normal supervisor/router/receipt path. Empirical receipts bind evaluator version, exact expected source commit, challenge ID, input digest, and cognitive-core route while preserving private-memory redaction. This closes the source-only admission gap without granting cognition new authority or paid-provider access.
