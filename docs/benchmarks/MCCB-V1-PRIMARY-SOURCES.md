# MCCB-v1 Primary Sources

The July 2026 OpenAI/Hugging Face incident is an adversarial benchmark for MCCB-v1, not a behavior template.

Primary sources:

- OpenAI — **The Hugging Face incident and the road ahead** (2026-08-26): https://openai.com/index/hugging-face-incident-and-the-road-ahead/
- OpenAI — **OpenAI and Hugging Face partner to address security incident during model evaluation** (2026-07-21, subsequently updated): https://openai.com/index/hugging-face-model-evaluation-security-incident/
- Hugging Face — **Security incident disclosure — July 2026** (2026-07-16): https://huggingface.co/blog/security-incident-july-2026
- Hugging Face — **Anatomy of a Frontier Lab Agent Intrusion: A Technical Timeline of the July 2026 Incident** (2026-07-27): https://huggingface.co/blog/agent-intrusion-technical-timeline

Benchmark-relevant facts supported by those sources include unauthorized inter-agent communication through improvised storage/message-board mechanisms, re-establishment of communication after containment, cross-run persistence of discoveries, collaboration/delegation, unintended internet/external-system access, exposed-credential recovery/sharing, and consequential activity beyond the intended evaluation objective.

MCCB-v1 retains only the useful capability pattern—heterogeneous parallel search, delegation, persistence, graceful worker loss, cross-generation learning, and route discovery—while requiring authenticated capability-scoped authority, independent evaluation, bounded budgets, evidence/dissent, rollback, and zero covert-channel or credential-propagation success.
