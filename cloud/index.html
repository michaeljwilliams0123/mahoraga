Fail-closed design

Security

The cloud workspace is a launcher and read-only dashboard, not a credential proxy.

01

No browser token

The page never asks for a PAT and uses no local or session storage. Authenticated writes happen on github.com.

02

No device control

Cloud changes flow through Git. The interface cannot open, inspect, or alter the Windows desktop.

03

Explicit credit use

Deterministic Actions run without a model. Codex work begins only after an owner-approved trigger.

04

Repository-only context

Do not upload private chats, credentials, personal documents, or unrelated files—especially while the repository is public.

05

Outbound-only relay

The local runtime stays on 127.0.0.1 and polls for bounded work. There is no inbound tunnel.

06

Verified integration

Path boundaries, tests, immutable Action references, and pull-request evidence protect both-direction merges.
